# Audio

Drop licensed audio files here using the filenames already referenced in
`src/data/music.ts`:

- `landslide.mp3`
- `unwritten.mp3`
- `live-forever-in-me.mp3`
- `slipping-through-my-fingers.mp3`
- `deja-vu.mp3`

No code changes are needed — the player already points at these paths and
will start working the moment a file exists. If you'd rather link to a
licensed streaming embed instead of hosting a file, change the matching
`src` value in `src/data/music.ts`.
